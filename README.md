# Retail-Shop-Automation
Small Retail Shop Automation System using Excel, VBA, SQL Server and Power BI

Overview
This project demonstrates how to automate the daily operations of a small motorcycle and bicycle parts store using Microsoft Excel, VBA, SQL Server, and Power BI.

Features
- Inventory Management
- Purchase Orders
- Sales Processing
- Expense Tracking
- Dashboard Reporting
- Profits Analysis

Technologies
- Excel
- VBA
- SQL Server
- Power BI

Skills Demonstrated
- Data Modelling
- SQL
- Reporting
- Dashboard Design
- Automation
- SDLC Documentation
